## 🔬 Featured Work

**🧪 Improving ML-Based Malware Detection Under Concept Drift** (MSc dissertation)
Evaluated the pretrained **EMBER** and **SOREL-20M** detectors across 166,000+ samples from independent datasets. ROC-AUC stayed above 99% everywhere, but the **Population Stability Index** showed drift up to 5× the "major shift" threshold. SHAP analysis showed red-team payloads (Cobalt Strike, Metasploit) evaded detection more often than ordinary crimeware.

**🖥️ Host Anomaly Detection System**
Collected process, memory and network telemetry, engineered features, and trained an **Isolation Forest** to learn normal host behaviour and flag anomalies.

**🌐 SOC Portfolio: [karuppasec.co.uk](https://karuppasec.co.uk)**
An interactive site where a terminal detects and blocks a simulated brute-force attack, Linux and Windows logs (real event IDs) stream into a SIEM, and there's a small 3D world to drive around.
